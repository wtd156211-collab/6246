# 期望结果与判定口径

`samples/expected/<样例>.txt` 与 `samples/schema/<样例>.json` 一一对应，每行一条可独立核对的检查项；三个样例的分布不同、
约束不同，期望值也各自算好，不许互相套用。

## 1. 文件格式

每行 `<id> <期望> <容差>`，单个空格分隔；`#` 开头是注释行；容差写 `-` 表示这条不看容差。`id` 语法见第 4 节。

## 2. 桶怎么划

| 列 | 桶 | 桶键 |
| --- | --- | --- |
| 分类列（`categorical`） | 每个声明取值一桶 | `=值`，字符串带双引号：`="north"`、`=true`、`=18` |
| `int` 列（`uniform`/`zipf`/`ref_*`/`offset`） | 值域等宽 K 桶 | `[a,b)`，末桶 `[a,b]` |
| `float` 列（`uniform`） | 值域等宽 K 桶 | 同上，边界写 4 位以内小数 |
| 字符串列（`uniform`，按值长度） | 长度域等宽 K 桶 | `L[a,b)`，末桶 `L[a,b]` |

`K = min(hist_bins, 可取个数)`（`float` 直接取 `hist_bins`）。`int` 与长度域的边界是 `p_k = lo + floor(k×N/K)`，
`N = hi − lo + 1`，左闭右开、末桶右闭；`float` 边界是 `lo + (hi−lo)×k/K`。值域取列上的 `min`/`max`，`offset` 列取
`[基准列最小+min, 基准列最大+max]`，外键列取被引用列的取值集合。空值不进直方图，只统计 `null_count`/`null_ratio`。
`serial` 列与自引用外键列不判桶。

## 3. 期望占比与容差

分母是这张表的**总行数**（含空值）：非空各桶 `(1 − null_rate) × 桶内权重和 / 总权重`，空值比例 `null_rate`。

权重：`uniform` 每个可取整数等权（`float` 按连续均匀，每桶 `1/K`）；`categorical` 用 `weights` 归一化；`zipf` 第 k 个取值
权重 `∝ k^−exponent`（`int` 列 k 从 1 数到 N、值 = `min+k−1`；外键列按被引用键升序位置数）；`offset` 列是基准列分布与
`[min,max]` 上均匀增量的卷积。

判定 `|实测占比 − 期望占比| ≤ 容差`：容差是绝对差，默认 `0.02`（2 个百分点），列上 `tolerance` 覆盖；期望为 0 的桶必须
实测为 0。行数被 `--rows-scale` 缩放（非 1.0）时容差按 `tolerance × max(1, √(1/scale))` 放宽。

## 4. 每类 id 怎么判

| id | 期望 | 判定 |
| --- | --- | --- |
| `rows:<表>` | 行数 | 精确相等 |
| `columns:<表>` | `列名:类型,…` | 键集合、类型与顺序完全一致 |
| `nullratio:<表>.<列>` | `null_rate` | 差 ≤ 容差；每列都有一条 |
| `unique:<表>.<列>` | 行数 | 该列全表唯一且无空值 |
| `uk:<表>.<列>+<列>` | `pass` | 复合键元组全表唯一且无空值 |
| `fk:<表>.<列>-><表>.<列>` | `pass` | 每个非空外键值都能在被引用列的结果里找到 |
| `ineq:<表>.<左><op><右>` | `pass` | 逐行成立；任一侧为空的行跳过（同 SQL CHECK） |
| `bucket:<表>.<列>#<桶键>` | 期望占比 | 差 ≤ 容差 |

## 5. 唯一性与引用完整的检查说明

- 唯一性：单列取 `set(列值)`，与行数比；复合唯一键取元组集合，与行数比；出现空值直接判失败。唯一列、复合唯一键的列都
  不许为空。
- 引用完整：被引用列的值先收进集合（或排序归并），再逐行查非空外键值是否命中；自引用按「引用行必须已经落盘」生成，但
  检查时按**最终结果**全量比对，`null_ok` 为 true 的列允许空值。
- 分布检查：按第 2 节重新分桶、统计、与期望比；实测值与判定都要写进 `report.json`，页面画的就是同一份数。

## 6. 噪声余量

样例的行数是按「容差 ≥ 5σ」选的（σ = √(p(1−p)/行数)，p 是期望占比），这样换 PRNG 也压不出假失败。出题时用 25 个种子
各跑一遍三个样例共 137 条期望，全部通过，最紧一条用掉 44% 的容差。
